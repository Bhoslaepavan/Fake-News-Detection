# Fake News Detection

A Machine Learning and NLP project that classifies news articles as **Fake or True** using TF-IDF and a trained Machine Learning model.

## Technologies
- Python
- NLP
- TF-IDF
- Scikit-learn
- Pandas

## Files
- `Fake_True.ipynb` – Project notebook
- `fake_news_model.pkl` – Trained model
- `tfidf_vectorizer.pkl` – TF-IDF vectorizer
